# EspControl branding

`espcontrol.svg` is the supplied EspControl logo used as the vector source for the integration artwork.

The source repository provides the artwork under the [PolyForm Noncommercial License 1.0.0](https://polyformproject.org/licenses/noncommercial/1.0.0/). Preserve that notice unless the artwork owner explicitly licences these copies under different terms.

The integration bundles raster exports under `custom_components/immich_frames/brand`:

- `icon.png`: 256 × 256 pixels.
- `icon@2x.png`: 512 × 512 pixels.

Both are transparent raster exports of the supplied white mark, without a background box. Keep the SVG source and PNG exports in sync when changing the icon.
