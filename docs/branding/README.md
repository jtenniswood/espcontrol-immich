# EspControl branding

`espcontrol.svg` is the existing EspControl Companion app icon, reused from [`macos/Companion/Packaging/AppIcon.svg`](https://github.com/jtenniswood/espcontrol/blob/70fc13ebd5238939a40944d0baf1b7e15cdaaaed/macos/Companion/Packaging/AppIcon.svg).

The integration bundles raster exports under `custom_components/immich_frames/brand`:

- `icon.png`: 256 × 256 pixels.
- `icon@2x.png`: 512 × 512 pixels.

Both retain the source's transparent corners and the same navy background and white mark for light and dark interfaces. Keep the SVG source and PNG exports in sync when changing the icon.
