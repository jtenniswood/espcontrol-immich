# EspControl Immich Companion

Bring your Immich photos into everyday view as a slideshow. This add-on selects photos, fits them to your screen and provides a browser preview and HTTP image API. Your originals stay in Immich and are never changed.

## Start a frame

1. Start the add-on and open its web UI.
2. Under **Immich connection**, enter your server address and [read-only API key](https://github.com/jtenniswood/espcontrol-immich/blob/main/docs/installation.md#immich-connection-and-permissions). Immich **3.2 or later** is required.
3. Name your frame, choose a connection and photo source, then select **Create frame**.

Choose your library, albums, memories or keyword searches. Adjust screen shape, photo fit, date range, orientation, portrait pairing and timing. Each frame has Previous, Pause/Resume and Next controls.

See the [complete add-on guide](https://github.com/jtenniswood/espcontrol-immich/blob/main/docs/container.md) for permissions, configuration, advanced filters, import/export and API access.

For native Home Assistant devices and automation controls, install the [HACS integration](https://github.com/jtenniswood/espcontrol-immich/blob/main/docs/installation.md). The add-on's frames are managed separately.
